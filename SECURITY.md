# NAKEBUSEN Security and Privacy Reporting

Report security issues privately through the contact route on the maintainer's GitHub profile or repository owner page. Do not publish customer information or live credentials in a public issue.

Never commit:
- Customer names, phone numbers, appointment records, or private messages.
- Customer photos or recordings without an approved basis and consent.
- Payment references, financial records, passwords, tokens, or private keys.
- Private supplier or staff records.

If sensitive information is exposed, restrict further access, remove or rotate exposed credentials where relevant, assess copies and logs, and follow the applicable incident process. Removing a file from the latest commit may not remove it from Git history.

This document does not assert that an online booking/payment service or automated security control exists.
